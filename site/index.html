Sign in with a GitHub token

Saving here makes a real commit in the repo under your own GitHub name, so each of us signs in with our own token. It is stored only in this browser.

  1. Open GitHub → New classic token (the link pre-selects the public_repo scope).
  2. Pick an expiry (e.g. 90 days) and click Generate token.
  3. Paste it below. You must already be a collaborator on the repo.
