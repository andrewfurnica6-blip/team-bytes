\section{Sprint 1: Project Creation}

\subsection{Goal}
Create a shared GitHub repository, add all group members, create a C\# project,
push it, and verify that every member can pull and compile the code.

\subsection{Finished}
\begin{enumerate}
  \item Created the GitHub repository \texttt{team-bytes}.
  \item Added the other two group members as collaborators. V 
  \item Created a C\# console project (\texttt{src/TeamBytes.csproj}, .NET 8) inside the
        solution \texttt{TeamBytes.sln}, following the proposed repository structure
        (\texttt{doc/}, \texttt{var/}, \texttt{src/}, \texttt{test/}).
  \item Each member pulled the repository and ran \texttt{dotnet build}. V 
  \item Created a \texttt{README.md}, that lists the team members and explains the project.
\end{enumerate}

\subsection{Extra tooling}
\begin{enumerate}
  \item We use GitHub Actions workflow to build the C\# code on every push, so broken code
        is noticed straight away.
  \item A small web editor (GitHub Pages) lets us edit these \LaTeX{} files in the
        browser. Saving commits straight to the repository, and a second workflow
        compiles the PDF automatically.
\end{enumerate}
